# 校园在线学习平台需求说明书

## 1. 项目目标与范围

面向学生、教师和管理员，提供课程发布审核、章节学习、作业提交与批改、限时考试与阅卷、讨论私信、进度查看和证书领取。范围包含八个基本模块、45 条功能需求和14个验收场景。

## 2. 技术方案

- Python 3.12、FastAPI、Uvicorn、SQLAlchemy、PyMySQL、Alembic。
- MySQL 8.4，独立数据库 `campus_learning`，字符集 utf8mb4。
- Vue 3、Element Plus、JavaScript，前端资源随源码提供。
- 用户名和密码登录，JWT 与登录会话校验，按角色及课程归属授权。
- 本地文件存储，课程素材及作业附件通过鉴权接口访问。
- 普通 PowerShell 启动；数据库程序路径与配置见 [README](../README.md)。

## 3. 用户角色与权限

### 3.1 角色定义

- **学生**：浏览已发布课程、加入课程、学习、提交作业、考试、参与讨论、与任课教师私信、查看本人进度成绩和证书。
- **教师**：审核通过后管理本人课程、资料、作业、考试；查看本人课程学生及学习情况；批改、回复讨论、收发课程私信。
- **管理员**：审核教师账号与课程，管理用户和角色、处理违规讨论、维护设置、执行备份恢复。

按三个业务角色分配权限，同时校验课程、题库和资料的归属。

### 3.2 权限矩阵

| 操作 | 学生 | 教师 | 管理员 |
|---|---|---|---|
| 浏览已发布课程简介 | 是 | 是 | 是 |
| 查看完整学习内容 | 已加入课程 | 本人课程；其他课程无默认管理权 | 管理查看 |
| 创建、编辑课程及资料 | 否 | 本人课程 | 管理全部课程 |
| 审核发布课程 | 否 | 仅提交审核 | 是 |
| 发布作业、考试及阅卷 | 否 | 本人课程 | 管理全部课程 |
| 提交作业、考试 | 本人已加入课程 | 无需提供学生作答入口 | 无需提供学生作答入口 |
| 查看学习记录和成绩 | 仅本人 | 本人课程学生 | 管理查看 |
| 删除讨论主题或回复 | 本人内容 | 本人课程内容 | 全部课程内容 |
| 私信 | 本课程任课教师 | 本人课程学生 | 无私信正文浏览入口 |
| 查看与打印证书 | 本人证书 | 本人课程证书记录 | 管理查看 |
| 用户审核、角色分配、系统维护 | 否 | 否 | 是 |

管理员不能通过系统管理页面浏览师生私信正文。所有接口同时校验登录状态、角色和对象范围；修改请求中的用户 ID、课程 ID 或附件 ID 不能扩大权限。


## 4. 功能需求

表内需求为当前功能范围，验证结果见验证说明。

### 4.1 用户管理（UM）

| 编号 | 需求与验收条件 |
| --- | --- |
| UM-01 | 学生可使用唯一用户名、姓名、邮箱、密码注册并登录；重复用户名/邮箱明确拒绝，密码不以明文保存。 |
| UM-02 | 教师可注册并选择教师身份，账号进入待审核状态；管理员通过后获得教师权限，拒绝时可见原因。待审核账号不能创建课程或考核。 |
| UM-03 | 管理员可查看、搜索用户，审核教师、启用/停用账号、分配三个业务角色；普通注册请求不能自行获取管理员权限。 |
| UM-04 | 登录用户可查看和修改本人姓名、邮箱及密码；修改密码需验证原密码，邮箱格式和唯一性在后端验证。 |
| UM-05 | 退出清除客户端登录凭据；受保护接口拒绝无效/过期凭据，停用账号的已有凭据不能继续访问业务接口。 |

注册字段不新增学籍认证、手机号验证码或教师工号对接。学生和教师使用同一注册/登录页面即可。

### 4.2 课程管理（CM）

| 编号 | 需求与验收条件 |
| --- | --- |
| CM-01 | 教师创建和编辑本人课程：名称、简介、课程大纲、封面；列表可按名称搜索并显示教师及发布状态。大纲可直接由章节标题与顺序形成。 |
| CM-02 | 教师在本人草稿课程内添加、编辑、删除、排序章节；每章支持文字、视频或文档之一，能够上传封面与资料并预览/下载。 |
| CM-03 | 课程按“草稿→待审核→已发布”流转；管理员可通过或驳回并填写原因。仅已发布课程进入学生课程列表；至少有一个有效章节才能提交审核。 |
| CM-04 | 已发布课程的教学内容、题目及考核配置在本期冻结；需要修改时由管理员在无学生加入、无提交记录的情况下退回草稿。已有学习记录的课程只提供归档，不直接删除。 |
| CM-05 | 上传限制在前后端一致：图片 JPG/PNG，视频 MP4，文档 PDF/DOCX；默认图片 5MB、文档/作业附件 20MB、视频 200MB。超限或格式错误给出明确提示，文件名不能用于目录穿越。 |

PDF 在页面内预览，DOCX 提供下载；不要求在线编辑或将 Office 文档转换为网页。课程分类沿用已有基础能力即可，不扩展复杂标签体系。

### 4.3 在线学习（LM）

| 编号 | 需求与验收条件 |
| --- | --- |
| LM-01 | 学生浏览已发布课程，按名称搜索、查看简介与大纲，点击“加入学习”进入我的课程；同一学生加入同一课程只产生一条成员关系。 |
| LM-02 | 已加入学生可从我的课程进入章节，播放视频、阅读文字、预览 PDF 或下载文档。未加入者只能查看简介，不能直接通过接口取得受限资料。 |
| LM-03 | 视频保存播放位置，重新进入时可以继续播放；视频播放结束可标记该章完成；文字和文档由学生点击“完成本章”。不增加人脸识别或复杂防快进要求。 |
| LM-04 | 章节详情可跳转本课程讨论、作业和考试；归档课程停止新加入与新提交，已加入学生仍可查看历史学习内容、成绩与证书。 |

学生自主加入只做一次点击，不做名额、审批或退课。可在现有 CourseAssignment 中用用户类型的记录表达成员关系，无需同时新建重复的选课业务；教师安排课程可继续使用同一关系。

### 4.4 作业与考试（AS / EX）

#### 4.4.1 作业

| 编号 | 需求与验收条件 |
| --- | --- |
| AS-01 | 教师为本人课程创建作业，填写标题、文字要求、截止时间、满分、评分说明及是否为必交作业；发布后学生可见。 |
| AS-02 | 已加入学生在截止时间前提交文字、一个附件或二者；至少有一项内容。截止前且尚未批改可修改提交，只保留一份当前提交，不实现版本历史。 |
| AS-03 | 教师查看本人课程提交列表、文字与附件，录入 0～满分之间的分数及评语；学生仅可查看自己的提交和批改结果。批改后刷新并重新登录仍保留成绩。 |
| AS-04 | 已截止不能新交或修改；未批改显示“待批改”，不能当作 0 分。发布后存在提交的作业不能删除或修改满分、必交标识。 |

作业采用人工批改，不另做题库式作业引擎、自动查重或多附件管理。作业评分说明用文字表达，不实现复杂评分维度配置。

#### 4.4.2 考试

| 编号 | 需求与验收条件 |
| --- | --- |
| EX-01 | 教师维护本人题库，支持单选、多选、判断、简答四类；题干、选项、正确答案/参考答案、分值可录入。选择题至少两个有效选项，答案必须与选项匹配。 |
| EX-02 | 教师从本人题库手动组卷，考试绑定本人课程，设置标题、题目与分值、开放起止时间、答题时长、及格百分比、最多尝试次数和评分说明。 |
| EX-03 | 已加入学生在开放时间内开始考试；后端验证成员身份、考试时间和次数，截止点为“开考时间+答题时长”与关闭时间的较早者。前端显示倒计时并在到期时提交，不能仅依赖客户端时间。 |
| EX-04 | 客观题自动判分：单选/判断完全正确得分，多选与正确选项集合完全一致得分；简答题有作答内容时由教师人工批改，留空（含仅空白字符）自动判 0 分并标记已批，无需人工批改。作答中不向学生返回正确答案和解析。 |
| EX-05 | 满分取本次考试固定题目分值总和，漏答计 0 分、不减少满分；重复题目答案与试卷外题目在后端拒绝；同一考试记录重复提交不得重复计分或占用额外次数。 |
| EX-06 | 含有内容且未批的简答题时状态为“待批改”，不生成最终通过结论；教师可从页面进入待批记录，填写各题分数与评语，全部题目批改后才产生最终成绩和通过结果。空白简答题的自动 0 分不阻塞最终结算。 |
| EX-07 | 学生查看本人已提交记录、客观得分、待批状态及最终成绩；教师查看本人课程考试的提交人数、待批记录和最终成绩列表。最终成绩按“得分/固定满分×100”与及格百分比比较。 |
| EX-08 | 保存试卷时固定题目、题型、答案规则及分值，开考时再复制为答卷快照；后续题库修改不改变已发布试卷或已开始答卷，存在作答时不能删除试卷。 |

不新增随机组卷、复杂统计图表、错题推荐或填空题判分规则。既有功能无需扩展；考试先保证四种题型和人工阅卷完整可用。

考试页面刷新后保留当前尝试、已保存答案与服务器截止时间，不能刷新获得额外时长或次数。无需服务器定时自动收卷服务：到期后不能追加答案，提交/再次访问时按此前已保存答案结束尝试并进入判分或待批；进行中及未形成最终结论的答卷不得视为通过或用于发证。不要求断网自动保存每次按键。

2026-10-30 补充确认：上述空白简答题自动 0 分规则同时适用于手动交卷和超时结算。漏答、空值、空字符串和仅空白字符均不进入人工阅卷；不追溯重算此前已提交或已最终发布的历史成绩。

### 4.5 互动交流（CO / PM）

| 编号 | 需求与验收条件 |
| --- | --- |
| CO-01 | 每门课程提供独立讨论区，已加入学生与任课教师可发布文字主题；显示标题、内容、作者与时间，按时间分页。 |
| CO-02 | 主题下可发表一级文字回复，学生可提问、分享心得，任课教师可答疑；不做多级楼中楼。 |
| CO-03 | 作者可删除本人主题/回复，任课教师可删除本人课程违规内容，管理员可管理全部课程讨论；删除主题后其回复不再可见。 |
| PM-01 | 同一课程的学生与任课教师可互发纯文字私信，按对方查看往来记录，显示发送时间与已读/未读；不开放任意用户搜索和陌生人私信。 |
| PM-02 | 私信正文仅发送者与接收者可访问；普通课程成员不能通过猜测消息 ID 读取内容，页面按打开或刷新获取新消息，无需 WebSocket。 |
| CO-04 | 作业批改完成、最终考试成绩发布、讨论主题收到他人回复、收到私信时提供站内未读提醒；刷新或打开对应页面可更新未读状态。通知不包含私信正文。 |

不做讨论图片、文件、表情、点赞、群聊和消息撤回。讨论只需主题列表与详情两个视图，私信可用联系人列表与消息面板完成。

讨论和私信统一放在课程内标签页/弹窗。归档后可读历史，停止新主题、回复和私信；讨论删除保留操作人及时间。会话按页打开时，只把该页实际返回的收件及对应提醒标为已读；通知仅携带必要跳转信息，不存放或展示私信正文。

### 4.6 学习进度跟踪（PR）

| 编号 | 需求与验收条件 |
| --- | --- |
| PR-01 | 学生查看每门已加入课程的已完成章节数、总章节数和进度百分比；整课进度为已完成章节数/有效章节总数，视频播放位置单独保存。重复完成同一章不累计次数。 |
| PR-02 | 学生在课程内查看作业的未提交/待批改/已批改状态、分数，以及考试的未参加/进行中/待批改/通过/未通过状态。 |
| PR-03 | 教师查看本人课程的学生名单、各学生章节进度、作业状态与考试最终成绩；只需表格与必要筛选，不新增复杂看板或导出。 |
| PR-04 | 只有全部章节完成才设置“学习已完成”；首次从未完成变为完成时发送一次学习完成通知，不因单章完成提前发送，也不因重复请求重复发送。 |

“学习已完成”只表示章节完成，不等于“考核通过”或“已获证书”，页面应分别展示。已有重新学习能力不作为本期必需入口，避免与证书规则产生额外状态分支。

### 4.7 证书颁发（CE）

| 编号 | 需求与验收条件 |
| --- | --- |
| CE-01 | 教师可为课程启用证书，并指定一场本课程考试作为结课考核；启用时必须配置有效考核。发布课程后冻结这些规则。 |
| CE-02 | 已加入学生同时满足：全部有效章节完成、所有必交作业已提交且已批改、指定考试至少一次最终成绩及格，才可领取证书；其他考试不影响证书资格。无必交作业时不增加作业条件。 |
| CE-03 | 学生点击领取，由后端重新核验条件并生成唯一证书；同一学生同一课程只能一份，重复点击或并发请求返回同一份记录。 |
| CE-04 | 证书显示编号、学生姓名、课程名称、颁发日期、平台名称；保存颁发时显示信息，学生可查看、打印或用浏览器另存 PDF。教师可查看本人课程颁发列表。 |

领取前的待批考核不得视为通过。为控制范围，本期不提供已最终发布成绩的重新评分入口、不修改已发证课程考核规则，也不增加证书撤销/重发工作流；若后续开放这些操作，须另行定义证书失效规则。

### 4.8 系统管理（SY）

| 编号 | 需求与验收条件 |
| --- | --- |
| SY-01 | 管理员集中处理待审核教师与课程，查看必要资料、通过或驳回；审核结果本人可见，审核操作记录操作人、对象、时间和结果。 |
| SY-02 | 系统设置只提供平台名称与是否开放注册；持久化后刷新仍生效，关闭注册后后端同步拒绝注册。上传限制使用部署配置，不做通用配置中心。 |
| SY-03 | 提供管理员执行的备份脚本与说明，备份 MySQL 业务库及上传文件，记录数据库版本、备份时间和文件清单，备份不放在可公开下载的 Web 目录。 |
| SY-04 | 提供恢复脚本与说明，在独立空库/目录恢复备份；恢复后抽查课程、作业附件、成绩和证书，验证记录与文件对应。覆盖目标前明确提示目标库与目录，不在普通页面上传 SQL 执行。 |
| SY-05 | 管理员可归档课程、停用用户；存在提交、成绩、证书等依赖时拒绝直接物理删除关键业务对象，并给出原因。保留操作追踪所需字段，不新增通用日志查询平台。 |

备份恢复允许通过脚本与操作说明验收，不要求网页备份中心、自动备份调度、云备份或在线灾备。凭据通过环境配置提供，不能写进源码、报告或命令行示例。

## 5. 核心业务规则

1. **课程归属**：每门课程只有一名任课教师，默认创建者；不实现助教、多教师协同或课程转让。
2. **课程成员**：学生自主加入已发布课程；成员关系唯一，所有学习、作业、考试、讨论均以课程范围校验权限。
3. **发布前准备**：教师在草稿阶段准备章节、作业、试卷和证书规则，相关内容随课程发布对学生开放；发布后只处理提交、评分和互动，不编辑教学结构。
4. **时间**：界面使用北京时间（Asia/Shanghai），服务端统一比较时间；截止边界为服务器时间达到截止时间即结束，不使用客户端时间判断资格。
5. **评分**：成绩不得小于 0 或大于对应满分；未批改与 0 分分别保存、展示。主观题得 0 分仍可表示“已批改”，不能用“是否得分”代替批改状态。
6. **最终成绩**：部分批改保持待批状态；重复保存同一批改不重复加分。提交数据库事务后重新加载，答案分数、评语、总分和状态一致。
7. **证书条件**：学习完成、必交作业批改完成、指定考试最终及格三项同时满足，才允许领取。作业不额外设置及格线，避免扩展规则引擎。
8. **重复请求**：加入课程、完成章节、交卷、发完成通知、领取证书均应避免重复产生业务结果；唯一约束或事务保证不能只放在按钮禁用逻辑中。
9. **资源访问**：私信、作业附件、成绩和受限课程资源通过后端鉴权；学生不能读取其他学生提交或考试正确答案，资料 URL 不能绕过身份和课程范围。
10. **内容输入**：讨论、私信、作业文字按纯文本展示；不直接执行或渲染用户提交的 HTML/脚本。

## 6. 页面与数据需求

### 6.1 最小页面清单

| 页面/区域 | 内容 |
| --- | --- |
| 登录与注册、个人中心 | 三角色入口、教师待审核提示、个人资料与密码 | 使用 |

### 6.2 数据实体建议

以下用于界定数据范围，不要求一项对应一张新表；详细字段、约束和 ER 图在设计阶段按现有模型确定。

| 实体 | 必要信息 | 来源 |
| --- | --- |
| 用户/角色/权限 | 账号、姓名、邮箱、密码摘要、角色、启停状态、教师审核状态及原因 | 原用户权限模型扩展 |
| 课程/章节/素材 | 教师、简介、大纲、封面、审核状态及原因、顺序、类型、文件信息 | 原课程素材模型扩展 |
| 课程成员/学习记录 | 学生、课程、加入时间；章节、播放位置、完成状态与时间 | 课程成员与学习记录 |
| 作业/提交 | 课程、要求、截止、满分、必交、评分说明；学生、文字/附件、分数、评语、批改人和时间 | 新增 |

## 7. 非功能与验收要求

### 7.1 基本质量要求

- **可运行**：按 README 在干净环境完成依赖安装、数据库迁移、演示数据初始化及启动；不依赖作者机器绝对路径。
- **访问安全**：密码摘要存储、后端权限检查、上传校验、资源鉴权有效；密钥和真实账号凭据通过环境配置提供。
- **数据一致性**：作业、成绩、学习记录和证书保存后刷新、重新登录、重启应用仍能读取；关键步骤使用真实 MySQL 8.4 验证。
- **易用性**：错误提示能说明原因，列表有分页；显示课程名称而非只有 UUID，待审核、待批改、零分等状态清楚区分。
- **演示规模**：至少准备 1 名管理员、1 名教师、2 名学生、1 门不少于 2 章的课程、1 份作业及 1 场含客观题和简答题的考试。
- **性能边界**：以本地/局域网小组演示为目标，不要求压测平台或高并发承诺；普通列表操作不应长时间无响应，视频上传不一次性读入全部文件到内存。

### 7.2 最小验收场景

|---|---|---|
| AT-01 | 学生注册可登录；教师注册待审核，审核前不能建课，管理员通过后可创建课程；重复注册被拒绝。 | UM-01～03 |
| AT-02 | 修改本人资料和密码持久化；无效邮箱拒绝；退出、过期凭据、停用用户不能访问受保护接口。 | UM-04～05 |
| AT-03 | 教师创建含两章的课程，上传封面、视频及文档；驳回原因可见，审核发布后学生才能学习。 | CM-01～03 |
| AT-04 | 学生搜索、查看简介并加入课程，重复加入不重复记录；未加入不能读取完整资料，其他教师不能编辑该课。 | LM-01～02、权限矩阵 |
| AT-05 | 视频继续播放、PDF 预览、DOCX 下载、章节完成及学习入口可用；两章完成后进度 100%，刷新保留。 | CM-02、LM-03～04、PR-01 |
| AT-06 | 作业发布、文字/附件提交、截止前修改、教师批改、学生查看全流程可用；截止后或批改后不能改交，其他学生不能读取附件。 | AS-01～04 |
| AT-07 | 四题型可配置与作答；未开放、超次数、未加入均拒绝；倒计时与服务器截止一致，刷新不增加时长。 | EX-01～04 |
| AT-08 | 重复答案、试卷外答案拒绝；漏答仍按整卷满分计算；重复交卷不重复计分，题库变更不影响作答快照。 | EX-05、EX-08 |

| AT-10 | 学生发讨论、教师回复、本人/教师按范围删除；师生互发私信，其他学生无法读取；未读提醒刷新后更新。 | CO-01～04、PM-01～02 |
