### 本轮实现

- 复用本机已有 MySQL 程序，新建项目专用实例与校园库，不使用原项目数据目录。
- 初始化脚本生成随机数据库密码、JWT 密钥与平台账号密码；重复运行不清库、不重置已有密码，也不覆盖用户已有配置。
- 迁移前核对有效数据库 URL 必须指向本项目 `campus_app` 与 `campus_learning`，已有配置指向其他库时拒绝执行。
- 启停脚本核对实际监听进程及项目路径，兼容 Windows 虚拟环境启动器 PID 与服务 PID 不同的情况，拒绝操作其他项目进程。
- 新增数据库就绪检查 `/api/v1/ready`；数据库不可访问或尚无迁移版本时返回 503，接口不回显内部错误。存活接口 `/health` 保持独立。
- 应用初始化数据库失败时停止启动，不再忽略错误后继续提供看似健康的服务。
- Alembic URL 配置处理编码密码中的 `%`；显式声明 PyMySQL 的 RSA 依赖。
- 去掉 Uvicorn `standard` 可选依赖，本期只需基础 HTTP 服务，不引入 WebSocket、监听重载等额外包；保留已有业务依赖版本。
- 生成 Windows x64 / Python 3.12 的运行依赖锁定清单（33 项）及开发清单（额外 3 项），排除参考环境中未使用的云 SDK。

## 阶段 4：学习与课程内作业（2026-10-27）

### 完成范围

- 学习汇总只计入当前有效章节；完成状态按章节完成数计算，与考试是否通过分别展示。完成一章不发整课通知，全部完成后发送一次；通知事件唯一标识及学生/章节唯一约束防止重复业务结果。课程行锁协调完成请求、课程状态变更和作业操作。
- 学习进度拒绝负时长、超出 0～100 的百分比和非法播放位置。重复完成不重复累计时长；旧课程级或已移除章节的记录不计入进度，也不作为续播入口。
- 移除原视频防快进、防倍速事件及隐藏进度条的 CSS。原生播放器定期或暂停时保存位置，返回课程自动选择上次章节，视频播放结束标记章节完成；文字和 PDF 通过按钮完成。
- 新增两张表：`homeworks`、`homework_submissions`。教师仅在本人草稿课程内准备作业，包含要求、截止时间、满分、评分说明和必交标识，随课程审核发布开放。无独立作业发布流程或多套详情页。
- 学生在已加入、已发布课程内，截止前提交文字、一个附件或二者；同一学生/作业只保存一份当前提交，支持截止前修改、替换或删除附件。附件限 PDF/DOCX/JPG/PNG、20MB，校验文件头和大小，使用随机存储路径，下载只允许本人及课程管理者。
- 教师通过课程内表格查看提交并填写分数和评语。0 分显示已批改，待批改保存为空；分数后端限制在 0～满分。已批改不能改交；重复保存批改覆盖当前结果，不重复发送首次批改通知。
- 教师用一张分页表查看本人课程学生的章节进度、作业已交/已批数量；具体分数和评语在该作业的共用提交表中查看。考试成绩列在阶段 5 接入。归档后保留历史作业及附件，不接受新提交。

## 阶段 5：精简考试与阅卷（2026-10-27）

### 本轮完成

- 继续复用题库表、题库管理表单和既有答题页面。教师只管理本人题库/题目，支持单选、多选、判断、简答；后端校验至少两个有效选项、标识和答案匹配、分值及题型。增加题目编辑；隐藏 Excel 导入、填空题等非本期入口，既有批量/导入/错题/分析接口限管理员。
- 课程内共用弹窗完成手动选题和逐题分值设置，填写开放起止、时长、及格百分比、尝试次数及评分说明。教师只管理本人课程；考试在草稿阶段准备并随课程发布，发布后不可修改/删除，有答卷不能物理删除。未加入学生、其他教师及待审教师均不能取得额外权限。
- 保存试卷时固定题目、答案规则及分值；开考时再复制到答卷快照，固定满分及及格百分比。后续题库编辑不改变已发布试卷或进行中的答卷。旧的无快照答卷保留，不借当前题库重新推算历史成绩。
- 服务器保存尝试的开始和截止时间，截止取“开始+时长”与考试关闭时间的较早者。课程/试卷/答卷行锁和尝试号唯一约束防止并发开考重复建卷。刷新复用进行中的尝试、已保存答案和原截止，不延长时间或多扣次数。
- 答题时不向学生返回正确答案/解析。选项变更或简答输入暂停后保存答案；截止后拒绝继续保存或追加答案，交卷/再次访问按此前已保存答案结束。客户端按服务器时间显示倒计时并到期交卷，不增加定时收卷服务。
- 交卷校验重复题目、试卷外题目、无效选项；漏答仍按全卷满分，客观题按匹配规则计分，多选按集合完全一致计分。重复交卷返回同一次结果，不再次计分。
- 简答题独立保存已批状态，0 分也可已批。部分批改保持待批、最终结论为空；全部批完才按总分/固定满分比较及格百分比。每次以新 JSON 值写回并重算总分，重复保存不累加，首次最终成绩通知使用唯一事件标识去重。
- 同一答卷弹窗用于学生查看和教师阅卷，成绩列表显示进行中/待批/最终通过或未通过。教师课程学生表补充最终考试成绩；作业与学习页面复用，不新增统计图、看板或多套详情页。
- 删除已无调用的旧建卷/计分/阅卷/答卷展开方法，以免误用旧的漏答减满分、重复计分和提前结束批改逻辑。保留已有 API 路径及仍被使用的题库服务；不做额外架构改造。
